# Machine Learning Lab 4 — Data Quality Pipeline

## Project Overview

This project uses the UCI Adult dataset to practise data quality
assessment and preparation for machine learning.

## Objective

Build a reproducible pipeline that validates, cleans, and transforms
data before training a binary classification model.

## Dataset

- Source: OpenML
- Dataset: Adult
- Expected rows: 48,842
- Expected columns: 15
- Target: class

## Planned Tasks

1. Define the dataset and ML problem.
2. Implement data ingestion.
3. Validate the data.
4. Clean and transform the data.
5. Perform feature engineering.
6. Check label quality.
7. Implement reproducibility, hashing, and a data card.
